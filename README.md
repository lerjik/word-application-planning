# Planificarea Aplicației Microsoft Word

Acest repository conține materialele de planificare și analiza cerințelor pentru aplicația desktop **Microsoft Word** (inclusiv documentul Word aferent).

## Despre proiect
Proiectul prezintă cerințele funcționale și non-funcționale ale aplicației Microsoft Word, structura specificațiilor tehnice și gestionarea versiunilor prin Git și GitHub.

## Funcționalități principale analizate
- Crearea, editarea și salvarea documentelor text (`.docx`)
- Formatarea textului, tabelelor, listelor și imaginilor
- Verificarea ortografică și exportul documentelor
- Lucrul rapid, stabilitatea și interfața intuitivă
